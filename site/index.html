Aizome

ローカルAIが補完してくれる、静かなコードエディタ。書いたコードは、その場のターミナルですぐ試せます。

最新版を確認しています

    できること

    AI 補完
    入力を止めると、ローカルAIの候補が薄く表示されます。Tab で確定。コードは PC の外に出ません。
    多言語
    Python、TypeScript、Rust、Go、C/C++ など100以上の形式を色分けします。
    その場で実行
    F5 で、開いているファイルを下のターミナルで実行します。
    拡張機能
    フォルダを追加するだけで、コマンドやテーマ、実行方法を増やせます。

    初めて開くとき

    今の配布版には開発元の電子署名が入っていないため、初回だけ OS の確認画面が出ます。

    Windows
    1. ダウンロードした Aizome_…_x64-setup.exe をダブルクリックします。
    2. 「Windows によって PC が保護されました」と出たら、詳細情報 → 実行 を押します。
    3. 画面の案内どおりに進めると、スタートメニューに Aizome が追加されます。
    Mac
    1. ダウンロードした .dmg を開き、Aizome を「アプリケーション」フォルダへドラッグします。
    2. アプリケーションフォルダの Aizome を 右クリック → 開く を選び、確認画面でもう一度 開く を押します。
    3. 開けないときは「システム設定」→「プライバシーとセキュリティ」の下にある このまま開く を押します。
    Linux

    AppImage はインストール不要です。実行できるようにしてから起動します。

    chmod +x Aizome_*.AppImage
./Aizome_*.AppImage

    Ubuntu や Debian なら .deb も使えます：sudo apt install ./aizome_*.deb

    AI 補完を使うには

    AI はあなたの PC の中で動かします。インターネット上のサービスには送りません。

    1. Ollama をインストールします。
    2. ターミナルで次を実行して、コード用のモデルを入れます。
      ollama pull qwen2.5-coder:1.5b
    3. Aizome を起動し、右上の滴のマークが青ければ準備完了です。GPU がある PC なら qwen2.5-coder:7b も快適に動きます。
    Aizome はオープンソースです。
