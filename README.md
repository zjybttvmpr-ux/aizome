# Aizome（藍染）

ローカルAIでコード補完ができる、拡張しやすい多言語コードエディタです。Windows・Mac・Linux で動きます。

- **AI 補完**：入力を止めると、ローカルAI（Ollama など）の候補が薄く表示されます。Tab で確定、Ctrl/Alt+→ で1語ずつ確定、Esc で消せます。
- **多言語**：CodeMirror 6 の言語パックで、Python・JavaScript/TypeScript・Rust・Go・C/C++・Java・PHP・Ruby・HTML/CSS・SQL・Markdown など100以上の形式を色分けします。画面は日本語と英語に対応しています。
- **ターミナル**：下のパネルで本物のシェルが動きます。F5 か「実行」ボタンで、開いているファイルをすぐ試せます。出力に出た `main.py:12` のような場所はクリックで開けます。
- **拡張機能**：`extension.json` と `main.js` を入れたフォルダを追加するだけで、コマンド・テーマ・実行設定・言語を増やせます。拡張機能は Web Worker の中で動き、ファイルやターミナルを使うにはユーザーの許可が必要です。

### 0.3.0：日本語から組み立てる

どのファイルでも、目印の行の下に日本語で手順を書くと、AI がプログラムに組み立てます。

```
###構築py###
以下ループ
    空リストaを作る
    コンマ区切りの数字を入力してもらい、コンマごとに分けてaに入れる
    aを表示する
###終わり###
```

- 目印の行に出る「▶ 組み立てる」を押すか、ブロックの中で **Ctrl+Shift+Enter**
- `構築py` の `py` の部分で言語を選べます：py・js・ts・rs・go・c・cpp・java・cs・kt・swift・rb・php・lua・sh・ps1・html・dart（省略すると一覧から選べます）
- `###終わり###` は省略できます（次の目印かファイルの最後まで）
- 結果は確認画面に出ます。「下に挿入」「保存して開く」「保存して実行」から選べます
- 書いた日本語は各処理のコメントとして残り、あいまいな所は「仮定:」としてコードの先頭に書き出されます
- メニューの AI →「組み立て用のひな形を入れる」で見本が入ります
- 小さいモデル（1.5b）だと組み立ての質が落ちます。できれば `qwen2.5-coder:7b` 以上を使ってください

### 0.32.1：自動判定で「値しだいのエラー」は控えめな注意に

- 自動判定の AI は実行せずに読むので、`open("data.txt")` があるだけで FileNotFoundError と予想しがちでした。今は **実際にファイルがあれば何も出さず**、なければ「ⓘ ファイル「data.txt」がないとエラーになる可能性があります」と控えめに出します
- ZeroDivisionError の予想も「ⓘ n が 0 だと割り算できないので注意」に。割る数が 0 以外の数字のときは出しません（`/ 0` のように確かにエラーになるときは今までどおり ⚠）
- `int(input())` などの「数字以外が入力されるとエラー」も、同じく控えめな注意にしました

### 0.30.0：def の引数の種類・条件式・内包表記・and / or まで説明

- `def` の説明に、引数の種類（省略したときの値・`*args`・`**kwargs`・`/` と `*` の意味・型）と返すものの型を出します。省略時の値を `[]` や `{}` にしたときは注意も出します
- `__init__`・`__str__`・`__eq__` などの特別なメソッドが何のためのものかを出します
- 条件式（`"偶数" if n % 2 == 0 else "奇数"`、JavaScript などの `c ? a : b`）、内包表記（リスト・辞書・集合・ジェネレーター、`if` で絞りこむ形も）、`and` / `or` / `&&` / `||`、`is None` / `is not None` に対応
- `return a, b`（まとめて返す）、`x, y = …`（順に分けて入れる）、`print(*names)`、`print(…, end="")` / `sep=` も説明します
- `strftime("%Y-%m-%d")` の書式を「年-月-日」のように読みかえます。Python 3.12 から非推奨の `datetime.utcnow()` には、代わりの書き方を添えます

### 0.29.0：elif / else が「どの if の、どの条件が違ったときか」を説明・関数の説明を追加

- `elif` は「上の「score >= 80」ではなく、もし score >= 60 なら」、`else` は「上の「score >= 80」でも「score >= 60」でもないとき（どれにも当てはまらないとき）」のように、**上の if までさかのぼって条件を** 出します
- 入れ子のときは「（外側：「a > 0」のとき ＞ 「b > 0」ではないとき）」のように、外側の条件もつけます
- for / while の `else`（break せずに終わったとき）、try の `else`（エラーが起きなかったとき）にも対応。C#・Java・JavaScript などの `} else if (…) {` / `} else {`、Ruby の elsif、シェルの elif も同じです
- Python の組み込み関数（全 71 個：repr・ascii・compile・aiter・anext など）と、文字・リスト・辞書・集合・数のメソッド（format_map・isascii・rpartition・bit_count・to_bytes など）をすべて説明できるようにしました
- lambda・デコレーター（@property・@lru_cache など）・global・nonlocal・yield・raise・del・assert・with・match / case の行も説明します

### 0.28.0：行の説明で、関数やメソッドが何をするかまで日本語に

### 0.25.0：ほとんどの言語の文法チェック

- 1 行目の `## ○○ ##` か、下に出ている言語に合わせて、その言語の決まりで調べます
- **JavaScript / TypeScript・PHP・Kotlin・Swift・Dart・Go・Rust・C# / Java / C / C++**：かっこ・引用符の閉じ忘れ、「;」の前の「)」忘れ、`if (x > 1 {` など（JavaScript の正規表現 /…/ や `テンプレート文字列` も正しく読みます）。Dart は「;」忘れも
- **Ruby・Lua**：`end` の忘れ・多すぎ（字下げを見て、どのブロックの end を忘れたかを当てます）
- **シェル**：`if … fi`・`for … do … done`・`case … esac` の組、`then`・`do` の忘れ、`[$a -eq 1]` の空白忘れ
- **JSON**：最後の「,」、' の文字列、" のないキー、「,」「:」忘れ、コメント、True/None など（直し方つき）
- **HTML / XML**：タグの閉じ忘れ・閉じタグのまちがい・属性の引用符の閉じ忘れ
- **CSS**：「;」忘れ・{ } の閉じ忘れ
- 正しいコードに波線が出ないことを、言語ごとに確かめています

エディタの設定（左下の歯車）→「AI 補完」で、モデル名を選びます。「一覧を取得」を押すと、入っているモデルが候補に出ます。

- 補完には **FIM（途中埋め）に対応したコード用モデル** を使ってください。チャット用モデルだと、説明文が混ざることがあります。
- llama.cpp の `llama-server` や LM Studio を使うときは、「接続先の種類」を「OpenAI 互換」にして、エンドポイントを `http://127.0.0.1:8080` などにします。
- 右上の滴のマークが AI の状態です。考えている間は揺れ、つながらないときは赤くなります。クリックで詳細が出ます。

## ボタン一つで配れるようにする（GitHub）

このフォルダを GitHub のリポジトリに置くと、インストーラー作りとダウンロードページの公開を GitHub が自動でやってくれます。

1. GitHub で新しいリポジトリを作り、このフォルダの中身を push します。
2. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** にします。
3. バージョンのタグを付けて push します。
   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```
4. **Actions** タブで「Release」が終わるのを待ちます（20〜30分）。Windows・Mac・Linux のインストーラーがリリースに載ります。
5. ダウンロードページは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。開いた人の OS に合ったボタンが自動で出ます。

新しいバージョンを出すときは、`package.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の version を上げて、同じ番号のタグを push します。ページは自動で最新版を指します。

配布版には電子署名が入っていないため、初回だけ Windows や Mac で確認画面が出ます。開き方はダウンロードページに書いてあります。
