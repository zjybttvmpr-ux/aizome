# Aizome（藍染）

ローカルAIでコード補完ができる、拡張しやすい多言語コードエディタです。Windows・Mac・Linux で動きます。

- **AI 補完**：入力を止めると、ローカルAI（Ollama など）の候補が薄く表示されます。Tab で確定、Ctrl/Alt+→ で1語ずつ確定、Esc で消せます。
- **多言語**：CodeMirror 6 の言語パックで、Python・JavaScript/TypeScript・Rust・Go・C/C++・Java・PHP・Ruby・HTML/CSS・SQL・Markdown など100以上の形式を色分けします。画面は日本語と英語に対応しています。
- **ターミナル**：下のパネルで本物のシェルが動きます。F5 か「実行」ボタンで、開いているファイルをすぐ試せます。出力に出た `main.py:12` のような場所はクリックで開けます。
- **拡張機能**：`extension.json` と `main.js` を入れたフォルダを追加するだけで、コマンド・テーマ・実行設定・言語を増やせます。拡張機能は Web Worker の中で動き、ファイルやターミナルを使うにはユーザーの許可が必要です。

### 0.2.0 で増えたこと

- **見た目**：背景色・アクセント色の変更（明るい色なら文字が自動で暗くなる）、背景画像（濃さ・暗さ・ぼかし・表示方法）、エディタのフォント、画面の拡大縮小（Ctrl+; / Ctrl+- / Ctrl+0）

- **AI チャット**（Ctrl+Shift+A）：開いているファイルや選択範囲について質問できる。答えのコードはボタンでエディタに挿入
- **AI で書き換え**（Ctrl+I）：選択範囲を指示どおりに書き換え、何も選んでいなければ指示からコードを書く。確認してから適用。コメント付け・不具合修正の定型コマンドもあり
- **フォルダ全体の検索**（Ctrl+Shift+F）：大文字小文字・単語単位・正規表現
- **Markdown プレビュー**（Ctrl+Shift+V）、パンくず、集中モード（Ctrl+Alt+Z）、全画面（F11）
- **作業の便利機能**：最近開いたフォルダ（Ctrl+R）、前回のタブの復元、閉じるときの未保存確認、自動保存、保存時の行末空白の削除と最終改行、すべて保存、保存済みに戻す、タブの切り替え（Ctrl+Tab）
- **Git**：ステータスバーにブランチ名と変更数、ファイルツリーに変更（M）・未追跡（U）の印
- **左上のメニュー**（Alt+F）：ファイル・編集・表示・実行・AI・ヘルプ。新規作成、上書き保存、印刷（コードを行番号付きで）、元に戻す、置換、行の移動や複製、テーマの切り替え、キーボードショートカット一覧（Ctrl+K）、バージョン情報、終了（Ctrl+Q）など

### 0.3.0：日本語から組み立てる

どのファイルでも、目印の行の下に日本語で手順を書くと、AI がプログラムに組み立てます。

```
###構築py###
以下ループ
    空リストaを作る
    コンマ区切りの数字を入力してもらい、コンマごとに分けてaに入れる
    aを表示する
###終わり###
```

- 目印の行に出る「▶ 組み立てる」を押すか、ブロックの中で **Ctrl+Shift+Enter**
- `構築py` の `py` の部分で言語を選べます：py・js・ts・rs・go・c・cpp・java・cs・kt・swift・rb・php・lua・sh・ps1・html・dart（省略すると一覧から選べます）
- `###終わり###` は省略できます（次の目印かファイルの最後まで）
- 結果は確認画面に出ます。「下に挿入」「保存して開く」「保存して実行」から選べます
- 書いた日本語は各処理のコメントとして残り、あいまいな所は「仮定:」としてコードの先頭に書き出されます
- メニューの AI →「組み立て用のひな形を入れる」で見本が入ります
- 小さいモデル（1.5b）だと組み立ての質が落ちます。できれば `qwen2.5-coder:7b` 以上を使ってください

### 0.8.4：Tab で変なインデントが入る問題を修正

- 一覧の準備が終わる前に Tab を押しても、インデントではなく、一覧が出たところでその項目を入力します
- 単語や行の途中で Tab を押したときはインデントを入れません（インデントは行の頭か、範囲を選んでいるときだけ）
- 「for 〜 in 〜:」のような、改行や字下げまで入るひな形は、ただのキーワードより下に並べます

### 0.8.3：候補の一覧を Tab で入力

- 入力中の候補一覧が出ているときに **Tab** を押すと、選んでいる項目をそのまま入力します（↑↓ で選ぶ）。一覧が出ていないときの Tab は、これまでどおり AI の候補を確定します
- 一覧が出ていても AI の候補を確定したいときは **Alt+Enter**。Esc で一覧と AI の候補を両方閉じます
- 一覧の下に、使えるキーの案内を表示します
- 設定 → エディタ →「候補の一覧を入力するキー」で、Enter に戻すこともできます

### 0.8.2

- 入力中の候補一覧も UD デジタル教科書体で表示（AI の候補・行の説明と同じ「候補の文字」の設定に従います）

### 0.8.1：実行と候補一覧の改善

- **Python を実行しても「Python」とだけ出て終わる問題を修正**：Windows の「python」が Microsoft Store への案内用の仮のものだった場合は、本物の Python（py ランチャー、PATH に入っていない Python、Anaconda など）を探して使います。どこにもないときは、winget か Microsoft Store で入れるボタンを出します
- 実行が終わると「--- 終了しました・コード (0) ---」と表示します（0 なら正常に終わっています）
- **入力中の候補一覧を賢く**：打った文字で始まる名前だけを出し（`im` で RuntimeError などは出ない）、文の頭ではキーワードを先に、`〜Error` は except / raise のときだけ上に出します。このファイルで使っている名前を優先し、`import` の後ろではモジュール名、`import numpy as` の後ろでは `np` を出します。設定 → エディタ →「入力中の候補一覧」で、Ctrl+Space のときだけにもできます

### 0.8.0：行ごとの説明・いろいろな言語に対応

- **行の横に「何をするか」を表示**：`print("こんにちは")` の右に「← 「こんにちは」と表示します」のように薄く出ます
  - よくある書き方（表示・入力・繰り返し・条件・関数・代入・読み込みなど）はその場で説明します。Python / JavaScript・TypeScript / C・C++・Java・C#・Go・Rust / Ruby / シェルに対応
  - それ以外の行は、手を止めたときに AI が見えている行をまとめて説明します（✦ 印）。入力を始めると補完を優先して止まります
  - 設定 → エディタ →「行ごとの説明」で「ルール＋AI」「ルールのみ」「表示しない」を選べます。表示 → 「行ごとの説明を表示／非表示」（Ctrl+Alt+E）でも切り替えられます
- **AI に伝える「何語のファイルか」を拡張子から判断**：`// main.go (Go)`、`<!-- index.html (HTML) -->`、`-- query.sql (SQL)`、`# Dockerfile` など、約 80 種類の拡張子と Dockerfile・Makefile などの名前に対応。コメントの書き方も言語に合わせます

### 0.7.0：補完を意図に沿うように

- 単語の途中（例：`impo`）では今の行だけを補い、関係ない長いコードを出さないようにしました
- 複数行の候補は、新しい行の頭か `:` `{` `(` の直後だけ。ブロックが終わる（字下げが浅くなる）ところで止めます
- ファイルの先頭では「`# main.py`」のような見出しを付けて、何語のファイルかを AI に伝えます
- ほぼ空のファイルでは、短い候補だけにします
- AI の候補と補完の一覧を UD デジタル教科書体で表示（設定 → エディタ →「候補の文字」で変更可）

### 0.6.0：軽く、OS となじむように

- **軽く**：重い処理を画面と別に動かし、固まらないようにしました。プログラムがたくさん出力しても、まとめて描くので重くなりません（ターミナルは GPU で描画）。AI のモデルは 30 分は手元に置き、PC が遅いときは補完を頼む回数を自動で減らします
- **多重起動しない**：起動中にもう一度開いても、同じウィンドウが前に出ます
- **ドラッグで開く**：ファイルやフォルダを画面に落とすと開きます（.gguf は AI のモデルとして読み込み）
- **右クリック・プログラムから開く**：Windows では .py などの「プログラムから開く」の候補と、右クリックの「Aizome で開く」に出ます（いつも使うアプリは変えません。設定 → 情報で解除できます）。Mac・Linux でも「このアプリで開く」の候補に出ます
- **ターミナル**：「＋」の横の ▾ から cmd・PowerShell・Git Bash・WSL などを選べます。実行中のプログラムを止める（Ctrl+C）・もう一度実行のボタン。Windows でも日本語が文字化けしないように UTF-8 で動かします
- **補完がチャットの返事になる不具合を修正**：ファイルの最後でも途中埋めで補完し、説明の文章は候補に出しません
- **ウイルス対策ソフトに怪しまれにくく**：隠したスクリプトや reg.exe を使わず、Windows の仕組みを直接使うようにしました

## 必要なもの

| もの | 用途 | 入手先 |
|---|---|---|
| Node.js 20 以上 | 画面側のビルド | https://nodejs.org |
| Rust（stable） | アプリ本体のビルド | https://rustup.rs |
| Tauri の OS 別の準備 | WebView などの開発用ライブラリ | https://v2.tauri.app/start/prerequisites/ |
| Ollama（任意） | AI 補完 | https://ollama.com |

OS 別の準備の例：

- **Windows**：「C++ によるデスクトップ開発」を含む Visual Studio Build Tools と WebView2（Windows 11 には最初から入っています）
- **Mac**：`xcode-select --install`
- **Ubuntu / Debian**：`sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`

## 起動のしかた

```bash
npm install
npm run app        # 開発モードで起動（tauri dev）
```

配布用のインストーラーを作るとき：

```bash
npm run app:build  # src-tauri/target/release/bundle/ に出力
```

アイコンを差し替えたいときは、1024×1024 の PNG を用意して `npx tauri icon 画像.png` を実行してください。

## AI 補完の準備（Ollama の場合）

```bash
ollama pull qwen2.5-coder:1.5b   # 軽くて速い。GPU があれば 7b も実用的
ollama serve                     # 常駐していれば不要
```

エディタの設定（左下の歯車）→「AI 補完」で、モデル名を選びます。「一覧を取得」を押すと、入っているモデルが候補に出ます。

- 補完には **FIM（途中埋め）に対応したコード用モデル** を使ってください。チャット用モデルだと、説明文が混ざることがあります。
- llama.cpp の `llama-server` や LM Studio を使うときは、「接続先の種類」を「OpenAI 互換」にして、エンドポイントを `http://127.0.0.1:8080` などにします。
- 右上の滴のマークが AI の状態です。考えている間は揺れ、つながらないときは赤くなります。クリックで詳細が出ます。

## フォルダ構成

```
src/                  画面側（TypeScript）
  app.ts              全体の組み立て（タブ、保存、実行、コマンド）
  core/               設定・翻訳・コマンド・ネイティブ呼び出し（platform.ts）
  editor/             CodeMirror 6 と AI のゴーストテキスト（ghost.ts）
  ai/                 ローカルAIへのリクエスト管理と、候補の整形
  terminal/           xterm.js のパネルと「実行」設定
  extensions/         拡張機能ホストと Worker の中身
  ui/                 ファイルツリー、パレット、ダイアログ、設定画面など
  styles/app.css      見た目（色はすべて CSS 変数）
public/extensions/    組み込み拡張機能（テーマ、実行設定、ツールキット）
src-tauri/            アプリ本体（Rust）
  src/fsops.rs        ファイル操作
  src/pty.rs          ターミナル（疑似端末）
  src/ai.rs           Ollama / OpenAI 互換サーバーへの中継（ストリーミング）
  src/extensions.rs   ユーザー拡張機能の追加・削除
docs/                 拡張機能の作り方とサンプル
```

## ボタン一つで配れるようにする（GitHub）

このフォルダを GitHub のリポジトリに置くと、インストーラー作りとダウンロードページの公開を GitHub が自動でやってくれます。

1. GitHub で新しいリポジトリを作り、このフォルダの中身を push します。
2. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** にします。
3. バージョンのタグを付けて push します。
   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```
4. **Actions** タブで「Release」が終わるのを待ちます（20〜30分）。Windows・Mac・Linux のインストーラーがリリースに載ります。
5. ダウンロードページは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。開いた人の OS に合ったボタンが自動で出ます。

新しいバージョンを出すときは、`package.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の version を上げて、同じ番号のタグを push します。ページは自動で最新版を指します。

配布版には電子署名が入っていないため、初回だけ Windows や Mac で確認画面が出ます。開き方はダウンロードページに書いてあります。
